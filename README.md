# 🌸 Crescer Juntos

App de acompanhamento infantil com IA em português, inspirado no Guiding Growth.

## Funcionalidades

- 🎙️ Registro rápido por voz com IA (organiza automaticamente)
- 🌀 Comportamento com intensidade 1–5 e gatilhos
- 🌙 Sono com qualidade e duração
- 🍎 Alimentação com reações e novos alimentos
- 💧 Hidratação com meta diária
- 💊 Medicamentos com horário e efeitos
- 🏥 Saúde intestinal
- 📱 Tempo de tela por dispositivo
- ⭐ Marcos do desenvolvimento
- 📊 Gráficos semanais (sono, crises, humor, hidratação)
- 📄 Relatório para consultas (IEP, médico, terapeuta, plano 504)
- 👨‍⚕️ Equipe de apoio
- 📚 Biblioteca de recursos e artigos
- ✨ Alma — IA parceira 24/7 com próximos passos

## Como usar

Abra o arquivo `index.html` diretamente no Chrome ou Safari do celular.

## Tecnologias

- HTML/CSS/JS puro (single file, sem dependências)
- Anthropic Claude API (claude-sonnet-4)
- Web Speech API para reconhecimento de voz
- Fontes: Nunito + Playfair Display
